# 60-minute workshop: Your first hour with Git

**Audience:** students with no Git experience. **Group size:** 5 to 25. **Needs:** a laptop per person (or pairs) and a projector.

Branchline runs in the browser, so there is nothing to install.

| Time | What happens |
|---|---|
| 0:00 | **Hook (5 min).** Ask: "Has anyone lost work, or ended up with `essay_final_FINAL_v3.docx`?" Explain that Git solves this by saving snapshots. |
| 0:05 | **Demo (10 min).** Project Branchline. Do missions 1 to 4 live. Point at the three file areas on the right each time you type a command. |
| 0:15 | **Hands-on 1 (15 min).** Everyone completes missions 1 to 7. Walk around. Pair up anyone who is stuck. |
| 0:30 | **Conflict challenge (10 min).** Mission 8. Before they start, ask: "What do you think will happen if two people change the same line?" |
| 0:40 | **GitHub (10 min).** Show a real GitHub repo. Create one together, then explain that missions 9 and 10 are the same steps. |
| 0:50 | **Wrap-up (5 min).** Share the Branchline link and the GitHub repo. Ask for the feedback form. |
| 0:55 | **Feedback (5 min).** Hand out the three-question survey below. |

## Feedback survey (anonymous)

1. Before today, how comfortable were you with Git? (1 to 5)
2. After today, how comfortable are you? (1 to 5)
3. What was confusing, and what would you change?

## After the workshop

Record the date, number of attendees, and survey averages in [`impact-log.md`](impact-log.md) while you still remember the details. Turn confusing moments into GitHub issues.
